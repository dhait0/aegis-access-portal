# Implementation / Implementación

English:
The implementation focuses on:

- a strong hero with bilingual copy
- metric cards for access health
- an approvals queue
- a permission matrix
- an audit trail
- policy enforcement checks

- una cola de aprobaciones
- una matriz de permisos
